HOME CALISTHENICS V2 — 20 exercises, exercise enable/disable settings, persistent selections, offline use.

DEPLOY UPDATE TO GITHUB:
1. Extract this ZIP.
2. Open https://github.com/NHobday/home-calisthenics
3. Choose Add file > Upload files, and upload all contents of the extracted folder (not the ZIP).
4. Commit changes, replacing existing matching paths.
5. Open the app on your phone and reload it while online. If you see the old version, close and reopen, or clear site data if needed.

NOTICE: The 10 new animations are first-pass schematic line drawings; inspect exercise form before relying on them as technique instruction.
