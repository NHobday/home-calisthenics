HOME CALISTHENICS – VERSION 1A

To use on your PC:
- Open index.html in Chrome or Edge. Play/pause, next/previous and dropdown work.

To install on Android with offline support:
1. Upload the CONTENTS of this ZIP to a free HTTPS static website host, such as GitHub Pages.
2. Open that HTTPS web address in Chrome on Android.
3. Wait until the bottom says Ready for offline use.
4. In Chrome, tap the 3-dot menu, then Install app or Add to Home screen.
5. Launch the icon from your phone home screen.

GitHub Pages setup (free GitHub account required):
1. Create a new PUBLIC repository at github.com/new (e.g. home-calisthenics).
2. In the repo, choose Add file > Upload files. Drag in ALL the unzipped contents, including the frames folder. Commit changes.
3. Settings > Pages > Build and deployment > Deploy from a branch.
4. Branch: main; folder: /(root); Save.
5. Open https://YOUR-USERNAME.github.io/home-calisthenics/ when deployed.

No subscription or payment details are needed for GitHub Pages. You do need a free GitHub account.
